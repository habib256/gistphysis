Utiliser OptGeo sur le web

OptGeo est un logiciel libre d'optique géométrique écrit par Jean-Marie Biansan. Cette version web s'utilise dans le navigateur, sur une tablette, un téléphone ou un ordinateur. Les autres pages de l'aide reprennent l'aide d'OptGeo 3.03, écrite pour un ordinateur et une souris : cette page explique comment faire dans la version web.

L'écran

La barre du haut

  • Menu : Fichier, Édition, Ajouter par coordonnées, Affichage et options, Aide.
  • Annuler et Refaire : reviennent sur la dernière action, ou la refont.
  • Les modes d'OptGeo : Déplacer, Propriétés, Dupliquer, Supprimer, Grouper. Ils marchent comme dans OptGeo (voir l'aide générale). Pour sortir d'un mode, touche le bouton Terminer dans le bandeau de consigne.
  • Affichage : afficher ou non les normales, les angles, la grille, l'attraction de la grille, les longueurs des segments ; choisir le zoom, de ×1 à ×100.

La palette des objets

Elle est à gauche quand l'écran est en paysage (plus large que haut), en bas quand il est en portrait (plus haut que large). Elle range les objets en cinq familles : Miroirs, Écrans, Sources, Dioptres, Divers.

Placer un objet

  1. Choisis un objet dans la palette.
  2. Lis le bandeau en haut du dessin : il dit quoi faire à chaque étape.
  3. Place les points de l'objet un par un, comme dans OptGeo :
    • au doigt : appuie, glisse pour viser (une loupe montre ce qui est sous ton doigt et les coordonnées), puis relâche pour valider le point ;
    • à la souris : un clic par point ; l'aperçu de l'objet suit la souris.

Pour abandonner : bouton Annuler du bandeau, ou touche Échap.

Pour t'aider :

  • la case Rester dans ce mode permet de créer plusieurs objets à la suite ;
  • les boutons Aligner horizontalement et Aligner verticalement (ou les touches Ctrl et Alt à l'ordinateur) placent le point sur la même horizontale ou la même verticale que le point précédent ;
  • si l'attraction de la grille est activée (bouton Affichage), les points se placent sur la grille.

Choisir et modifier un objet

Touche (ou clique) un objet : il est sélectionné et ses poignées apparaissent.

  • Croix verte : déplace tout l'objet.
  • Cercle bleu : déplace ce point seulement (extrémité, sommet, source…).
  • Disque rouge : fait tourner l'objet.
  • Croix cyan : foyer ou centre de courbure ; la déplacer change la focale ou le rayon de courbure.

Fais glisser une poignée pour modifier l'objet. Tu peux aussi faire glisser l'objet lui-même pour le déplacer.

Sous le dessin, une barre propose : Propriétés, Dupliquer, Supprimer, Grouper / Dissocier, Désélectionner.

Plusieurs objets au même endroit ? Touche de nouveau au même endroit : la sélection passe à l'objet suivant.

Se déplacer dans le dessin

  • Au doigt : pose deux doigts pour zoomer et déplacer la vue.
  • À la souris : la molette zoome.
  • Glisser dans une zone vide du dessin déplace la vue.
  • Boutons +, − et Tout voir.

Ouvrir, enregistrer, imprimer

Avec le bouton Menu, tu peux :

  • ouvrir un fichier .opt de l'appareil ; tu peux choisir en même temps le fichier .txt de son commentaire ;
  • ouvrir un des 56 exemples d'OptGeo ;
  • superposer une simulation ;
  • enregistrer : le navigateur télécharge un fichier .opt, lisible par OptGeo 3.03, et un fichier .txt pour le commentaire ;
  • exporter une image PNG ou SVG ;
  • imprimer (seul le dessin est imprimé).

Ton travail est gardé automatiquement sur l'appareil : rien n'est envoyé sur Internet. Quand tu rouvres l'application, elle propose de reprendre ce travail.

Ce qui change par rapport à OptGeo 3.03

  • On fait glisser les poignées, au lieu de « cliquer, déplacer, cliquer ».
  • Pendant un déplacement, la touche Échap ou un deuxième doigt posé sur le dessin remet l'objet à sa place.
  • Dans les propriétés, les angles se saisissent en degrés (le fichier .opt garde les radians).
  • Dans les nombres, la virgule et le point sont acceptés (1,5 ou 1.5).
  • Ctrl+S enregistre (dans OptGeo, il supprimait).
  • Pas d'export JPG ni PostScript.
  • L'impression passe par le navigateur.
